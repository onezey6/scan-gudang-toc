🔧 Bagaimana Cara Memasangnya di Laravel?

Pemasangannya sangat bersih dan rapi, hanya membutuhkan 3 langkah:

  1. Buka Telegram, chat ke @BotFather untuk dapat Token Bot (gratis dalam 1 menit).
  2. Simpan token di file .env web kita:
    TELEGRAM_BOT_TOKEN=789...
    TELEGRAM_CHAT_ID=-100...
  3. Buat Service TelegramBotService.php di Laravel untuk mengirim notifikasi secara otomatis saat scan/jatuh tempo.
